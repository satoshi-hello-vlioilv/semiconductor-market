Slide 03 // Layer 01
⚗️ 原材料・素材層
半導体製造の「土台」。日本企業が14種類の重要材料で世界シェア50〜100%を独占する最上流層。⭐ GNT認定企業多数。
Slide 04 // Layer 02
⚙️ 製造装置・EDA層
EUV露光から洗浄・検査・テストまで。米・蘭・日の3か国で市場85%以上を独占する「装置の壁」。
Slide 05 // Layer 03 + 04
🧩 IPコア・ファブレス設計層
設計知財（ARM独占）とファブレス設計（NVIDIA一強）。製造を持たずに最大収益を生む新時代の構造。
Slide 06 // Layer 05 — Foundry
🏭 ファウンドリ層
TSMC一強（70%超）。2nm（N2）量産が2025年Q4に始動し2026年に加速。Samsung・Intel（18A）・Rapidusが追走する製造覇権争い。
Slide 07 // Layer 05 — Memory IDM
💾 メモリ・IDM層
AIメモリ・スーパーサイクルが本格化。HBM4量産開始（2026年2月）。SK hynix 62%独走・Micronが2位浮上、DRAM/NAND価格も歴史的急騰。
Slide 08 // Layer 06
📦 後工程・OSAT層
AI時代の真のボトルネック。CoWoS（TSMC独占・2027まで満杯）とHBM組立が供給制約の核心。
Slide 09 // Layer 07
🖥️ 最終製品・需要層
AI/DC・スマホ・車載の三大需要。NVIDIA独走のAI、MediaTek首位のモバイル、欧州主導の車載。
Slide 10 // Japan Deep Dive
🇯🇵 日本企業 深掘り — 4社の完全解説
オキサイド・レーザーテック・信越化学・アドバンテスト。表舞台に出ない「隠れた独占」の全貌。
